# Team PI website V4: source and publication notes

Prepared 19 November 2026 from the user-supplied Team PI V4 ZIP. The visual design, illustrations, map geometry, presentation, glossary, source figures and saved-prediction interface come from that package. Original research calculations and model results were not modified or refitted.

The global saved demo has 6,331 crop observations from 142 countries/territories, 1996–2015. Weather map evidence represents 2,825 distinct national country-years, not independent values for every crop row. Country-level matched stability contains 183 crop-country statistics across 61 countries. Fixed map bands are display choices, not significance tests. The regional rice/maize demo has 194 observations on 97 country-years. Its comparison widget calculates raw t/ha MAE on identical selected saved rows, not the official normalized aggregate MAE.

The supplied weather anomalies and matched SD/sample values were independently reconciled to the original Global V3 tables at the package's six-decimal precision. The existing demo JSONs and source figures are unchanged. There is no new model training, future forecast, causal identification, raw-data dump or interpolation of missing years.

## Credits and reuse

Illustrations in `assets/ui/` are provided AI-generated design illustrations, not documentary photographs. Country geometry is adapted from Natural Earth; its [terms](https://www.naturalearthdata.com/about/terms-of-use/) state that the data are public domain. Map boundaries are illustrative and small territories may lack shapes. Original asset credits remain in `assets/ui/CREDITS.txt`.

Yield: FAO and supplementary providers, processed by OWID. Climate: modified Copernicus Climate Change Service information, processed by OWID. Fertilizer: FAO → OWID; irrigation: FAO → World Bank → OWID. Specific source pages, retrieval dates, variable definitions and resource-specific limitations remain on the source cards and in the evidence guide. General [FAO database terms](https://www.fao.org/contact-us/terms/db-terms-of-use/en) describe default attribution licensing with dataset/third-party exceptions; the [ERA5 source catalogue](https://cds.climate.copernicus.eu/datasets/reanalysis-era5-single-levels-monthly-means?tab=overview) lists a CC-BY licence. These general current statements do not replace resource-specific historical metadata. No blanket licence is assigned to all third-party data or the team's code. No provider endorsement is implied.

## Scope and verification limits

Research document links outside the supplied compact package are identified as local-archive references instead of being offered as broken downloads. Three original findings reports are included for the artifact-page report links. The publication manifest lists the actual static export, not an older broad staging plan. Original training inputs, binaries, README changes, environment files, caches, private paths, review tools and backups remain outside the publication.

Source/data, DOM integration and actual HTTP checks are recorded in the local V4 import review. Browser control was unavailable, so real desktop/mobile appearance and native browser console behavior cannot be certified from these checks. The supplied design's CSS/images are retained, with only necessary link/metadata and verified functional fixes. This website remains a research communication tool, not an operational prediction service.
